# روشنا (Roshana) — پروتوتایپ تعاملی UX/UI

پروتوتایپ تصویری، قابل اجرا و قابل کلیک برای ارزیابی تجربه کاربری (UX)، معماری اطلاعات، جریان‌های کلیدی دانش‌آموز و معلم، و ساختار واقعی RTL در پلتفرم آموزشی **روشنا**.

> **توجه مهم:** این مخزن یک **نسخه اکتشافی UX/UI Prototype (نسخه ۰.۱)** است و محصول نهایی (Production) محسوب نمی‌شود. تمام داده‌ها نمایشی (`DEMO DATA`) هستند و هیچ منطق تأییدنشده‌ای (مانند فرمول SmartScore، قواعد تسلط، یا موتور پیشنهاد هوشمند) به‌عنوان رفتار قطعی محصول معرفی نشده است.

---

## ۱. راه‌اندازی و اجرای پروژه

پیش‌نیاز: `Node.js >= 18` و `npm`.

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای محیط توسعه (Development Server)
npm run dev

# ۳. بررسی تایپ‌ها و ساخت نسخه Build
npm run build

# ۴. پیش‌نمایش نسخه Build
npm run preview
```

پس از اجرای `npm run dev`، برنامه روی آدرس محلی `http://localhost:5173` در دسترس خواهد بود.

## ۲. ابزارهای ارزیابی پروتوتایپ (Preview Toolbar)

در بالاترین بخش صفحه، یک نوار تیره مجزا با برچسب **`DEMO DATA`** قرار دارد که **صرفاً ابزار ارزیابی پروتوتایپ** است و بخشی از رابط نهایی محصول نیست:

1. **تغییر نقش پیش‌نمایش (Role Switcher):** جابه‌جایی فوری بین تجربه مستقل **دانش‌آموز (آوا رضایی)**، **معلم (خانم مریم احمدی)** و صفحه Placeholder **والدین / مدیر مدرسه** (در محصول واقعی نقش پس از ورود به‌صورت خودکار از حساب مدرسه تشخیص داده می‌شود).
2. **شبیه‌ساز وضعیت‌های UX (State Simulator):** امکان تست فوری حالت‌های مرزی هر صفحه (مانند `بدون تکلیف`، `چند تکلیف`، `تکلیف دیرشده`، `اولین ورود`، `بدون پیشنهاد`، `داده ناکافی`، `کلاس خالی`، `بارگذاری Skeleton` و `خطای شبکه`).
3. **تغییر زبان و جهت واقعی (`FA (RTL) | EN`):** تغییر زنده بین فارسی با چیدمان واقعی راست‌به‌چپ (`dir="rtl"`) و انگلیسی با چیدمان واقعی چپ‌به‌راست (`dir="ltr"`).
4. **بازنشانی داده‌ها (`بازنشانی`):** برگرداندن تمام تغییرات تعاملی جلسه (تکالیف منتشرشده، سکه‌های خرج‌شده، پیشرفت تمرین) به وضعیت اولیه.

## ۳. نقشه صفحات و مسیرها (Routes)

### ورود و نقش‌های خارج از دامنه فعلی
| مسیر | عنوان صفحه | اولویت | توضیح |
|---|---|---|---|
| `/sign-in` | ورود به حساب مدرسه | **P0** | فرم ورود بدون انتخاب نقش، مسیر مجزای «پیوستن به کلاس با کد کلاس» و راهنمای بازیابی رمز |
| `/roles-placeholder` | والدین و مدیر مدرسه | Placeholder | توضیح شفاف نیازمندی‌های باز بدون اختراع داده یا مجوز فردی |

### تجربه دانش‌آموز (Student UI)
| مسیر | عنوان صفحه | اولویت | قابلیت‌های کلیدی قابل کلیک |
|---|---|---|---|
| `/student` | خانه دانش‌آموز (Student Landing) | **P0** | کارت تکلیف بعدی، ادامه تمرین نیمه‌تمام، پیشنهادها با دلیل، هدف هفتگی، فعالیت اخیر و سکه ثانویه |
| `/student/skills` | کتابخانه مهارت‌ها (Skill Library) | **P0** | جست‌وجو، فیلتر پایه/وضعیت، و سوئیچ مقایسه دو الگوی UX: **مرور درختی در صفحه** در برابر **صفحه مستقل مبحث** |
| `/student/topics/:topicId` | جزئیات مبحث (Topic Detail) | **P0** | نمایش متمرکز مهارت‌های یک مبحث (با زیرمبحث در صورت وجود و بدون سطح خالی در مباحث مسطح) |
| `/student/practice/:skillId` | جلسه تمرین و بازخورد سؤال | **P0** | محیط کم‌حواس‌پرتی تک‌سؤالی، نمودارهای بصری ریاضی، بازخورد پاسخ درست و نادرست (همراه روش حل گام‌به‌گام)، خروج امن با ذخیره خودکار |
| `/student/analytics` | پیشرفت من (Student Analytics) | **P1** | خلاصه پیشرفت، نمودار هفتگی، جدول مهارت‌ها با ادبیات حمایتی (بدون برچسب قضاوتی «ضعیف») و اقدام بعدی |
| `/student/recommendations` | پیشنهادهای یادگیری | **P1** | کارت‌های پیشنهاد ثابت همراه با توضیح چرایی هر پیشنهاد و شروع مستقیم تمرین |
| `/student/achievements` | دستاوردها و تالار افتخار | **P2** | نشان‌های دریافت‌شده و نشان‌های قفل‌شده همراه با معیار دقیق دریافت |
| `/student/store` | فروشگاه آواتار (Rewards Store) | **P2** | پیش‌نمایش زنده نمادهای انتزاعی آواتار، خرید با سکه، حالت سکه ناکافی و شبیه‌سازی خطای تراکنش |

### تجربه معلم (Teacher UI)
| مسیر | عنوان صفحه | اولویت | قابلیت‌های کلیدی قابل کلیک |
|---|---|---|---|
| `/teacher` | پیشخوان معلم (Teacher Landing) | **P0** | برنامه امروز کلاس فعال، هشدارهای آموزشی توضیح‌پذیر با دکمه مستقیم تمرین جبرانی، موعد تکالیف و اقدام‌های سریع |
| `/teacher/classes` | مدیریت کلاس‌ها و دانش‌آموزان | **P0** | انتخاب کلاس (ششم الف ۲۴ نفر، ششم ب، هفتم الف خالی)، جست‌وجو/فیلتر، انتخاب چندنفره برای تخصیص تکلیف و Drawer خلاصه دانش‌آموز |
| `/teacher/skills` | کتابخانه مهارت‌ها (نمای معلم) | **P0** | مرور بانک مهارت‌ها با حفظ زمینه کلاس فعال، پیش‌نمایش نمونه سؤال (فقط مشاهده) و انتخاب چند مهارت برای تکلیف یا آزمون |
| `/teacher/assignments` | تکالیف و ویزارد ۵ مرحله‌ای | **P0** | فهرست تکالیف با ۷ وضعیت پیشنهادی + ویزارد ۵ مرحله‌ای کامل (انتخاب مهارت، گیرندگان، موعد، پیش‌نمایش «چه/کی/کی»، انتشار زنده) |
| `/teacher/analytics` | تحلیل عملکرد آموزشی | **P0** | فیلتر چهارگانه، تعاریف شفاف شاخص‌ها، مهارت‌های نیازمند توجه با دکمه `Assign Remedial Practice` و حالت‌های داده ناکافی/کلاس جدید |
| `/teacher/quiz-generator` | آزمون‌ساز از بانک سؤال | **P1** | انتخاب مهارت و پارامترهای نمایشی، تولید پیش‌نمایش فقط‌خواندنی از بانک سؤال، ذخیره پیش‌نویس و انتشار |
| `/teacher/timetable` | برنامه تدریس هفتگی | **P1** | نمای شنبه تا چهارشنبه با تمایز بصری «کلاس زمان‌بندی‌شده» از «موعد تکلیف/آزمون» |

## ۴. ساختار پوشه‌های پروژه

```text
src/
  app/
    App.tsx                  # تعریف مسیرها (React Router) و همگام‌سازی وضعیت‌ها
    PrototypeContext.tsx     # وضعیت مشترک درون‌حافظه‌ای بین دانش‌آموز و معلم
  components/
    ui/Primitives.tsx        # کامپوننت‌های پایه Design System (RTL-aware)
    shared/
      AppShell.tsx           # پوسته اصلی، Topbar، Sidebar دسکتاپ و Drawer موبایل
      PreviewToolbar.tsx     # نوار ابزار پیش‌نمایش پروتوتایپ و DEMO DATA
      Illustrations.tsx      # تصویرسازی‌های برداری آموزشی و نمودارهای سؤال ریاضی
    student/
      SkillCard.tsx          # کارت مهارت دانش‌آموز
      AssignmentCard.tsx     # کارت تکلیف دانش‌آموز
  data/
    types.ts                 # مدل‌های تایپ‌اسکریپت
    mockData.ts              # داده‌های نمونه فارسی/انگلیسی منطبق با بریف
  pages/
    auth/                    # صفحه ورود و کد کلاس مجزا
    student/                 # صفحات P0، P1 و P2 دانش‌آموز
    teacher/                 # صفحات P0 و P1 معلم
    shared/                  # صفحه Placeholder والدین و مدیر مدرسه
  styles/
    tokens.css               # توکن‌های پیشنهادی رنگ، تایپوگرافی، فاصله و ابعاد
    globals.css              # بارگذاری محلی فونت Abar و قواعد پایه RTL/LTR
  utils/
    format.ts                # تبدیل ارقام فارسی و متن دوزبانه
public/
  fonts/                     # فایل‌های محلی فونت Abar بدون وابستگی به CDN
  illustrations/             # دارایی‌های SVG محلی
screenshots/                 # تصاویر گرفته شده از صفحات کلیدی در دسکتاپ و موبایل
DESIGN_DECISIONS.md          # تصمیم‌های طراحی، یافته‌های UX و پرسش‌های باز محصول
QA_CHECKLIST.md              # چک‌لیست تست مسیرها، RTL و ریسپانسیو
```

## ۵. مرز دقیق قابلیت‌های واقعی در برابر Mock (محدودیت‌های فاز فعلی)

- **آنچه واقعاً در مرورگر کار می‌کند:** ناوبری کامل صفحات، جست‌وجو و فیلتر زنده روی داده‌های نمونه، ویزارد ۵ مرحله‌ای تخصیص تکلیف با اعتبارسنجی فیلدها (و نمایش فوری تکلیف جدید در نمای دانش‌آموز)، بررسی پاسخ در جلسه تمرین و نمایش بازخورد گام‌به‌گام، ذخیره جلسه نیمه‌تمام و ادامه آن از صفحه خانه، خرید آیتم آواتار با کسر سکه، تولید پیش‌نمایش آزمون از بانک سؤال، تغییر زبان/جهت RTL-LTR و ریسپانسیو کامل از `390px` تا `1440px`.
- **آنچه شبیه‌سازی (Mock) شده و نیازمند Backend واقعی در فاز توسعه است:** احراز هویت واقعی مدرسه، ذخیره‌سازی دائمی در پایگاه داده (داده‌ها در حافظه مرورگر هستند)، موتور پیشنهاد هوشمند، محاسبه واقعی SmartScore و تسلط، و تراکنش‌های سرور.
